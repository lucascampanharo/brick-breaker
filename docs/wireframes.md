# Wireframes

Os wireframes apresentados nesta seção representam a estrutura visual e funcional do **Brick Breaker**. Eles foram desenvolvidos para definir a organização das telas, os principais elementos de interação e a navegação dentro do jogo.

Foram desenvolvidas as seguintes telas:

## 1. Tela Inicial

A tela inicial é o primeiro contato do usuário com o jogo. Nela são apresentados o nome do **Brick Breaker**, sua identidade visual e os principais botões de navegação:

- **Iniciar:** inicia o jogo;
- **Configurações:** permite personalizar algumas características dos blocos;
- **Criadores:** apresenta a equipe responsável pelo desenvolvimento do projeto.

## 2. Tela de Criadores

A tela de criadores apresenta os nomes dos integrantes da equipe responsável pelo desenvolvimento do projeto.

Também possui um botão de retorno, permitindo voltar à tela anterior e acessar novamente as demais opções do menu.

## 3. Tela de Configurações

A tela de configurações permite que o jogador personalize alguns elementos do jogo antes de iniciar uma partida.

As opções disponíveis são:

- **Padrão dos blocos:** permite selecionar diferentes distribuições de linhas e colunas. A quantidade e a disposição dos blocos também influenciam na dificuldade da fase;
- **Cores dos blocos:** permite escolher entre diferentes conjuntos de cores disponíveis para os blocos.

Para definir as preferências, basta selecionar uma das opções disponíveis em cada configuração.

## 4. Telas das Fases

Cada fase possui uma distribuição diferente dos blocos, fazendo com que o nível de dificuldade aumente ao longo do jogo.

Apesar dessas diferenças, todas as fases mantêm os principais elementos do **Brick Breaker**:

- **Blocos:** devem ser destruídos durante a partida;
- **Bola:** utilizada para atingir e destruir os blocos. O jogador deve evitar que ela ultrapasse a plataforma;
- **Plataforma:** controlada pelo jogador e utilizada para rebater a bola.

## 5. Tela Final

A tela final é apresentada quando uma fase termina, seja porque o jogador deixou a bola cair ou porque conseguiu destruir todos os blocos.

Nela, são exibidas informações sobre o desempenho durante a partida, como a quantidade de blocos destruídos.

O jogador também pode escolher entre:

- jogar novamente a mesma fase;
- avançar para a próxima fase;
- sair da partida e retornar à tela inicial.

## Consistência visual e estrutural

Durante a criação dos wireframes, buscamos manter uma identidade visual e estrutural consistente entre as diferentes telas do aplicativo. Elementos como botões, controles de navegação, indicadores e componentes do jogo seguem padrões semelhantes de posicionamento e aparência.

Os elementos principais das fases também permanecem em posições semelhantes. Dessa forma, o jogador pode concentrar sua atenção na partida, sem precisar reaprender a interface a cada nova fase.
